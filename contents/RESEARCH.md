# Historical catalog additions

eBaum’s World (source row ID 80) was absent from the default Flash-era list because its only existing recorded snapshot was from 2007. The new picks include it across 1999–2009; new archive lookups found 2001, 2004 and 2009 captures. The 2004 page passed the title check and is preferred for the Flash era. Earlier/generic-title captures remain indexed rather than being promoted automatically.

The ten supplemental destinations were selected as recognizable portal, comic, game and social-web gaps in the existing catalog. They are editorial picks, not a measured popularity ranking. Each has an era-specific historical capture; capture dates are not claimed to be launch dates. Exact primary archive requests and page-title evidence are in historical-additions.json. The file also retains failures and the rejected DailyBooth maintenance page, so the check limits are reviewable.

The original source spreadsheet is unchanged: https://docs.google.com/spreadsheets/d/1GB6Phu1LnRdo4fT-gUjfM6H107KVO37v6Llc767Sg9Q/edit

Additional current primary references consulted for context include the eBaum’s World homepage (https://www.ebaumsworld.com/), Megatokyo (https://megatokyo.com/) and Neave Interactive (https://neave.com/). The archive records, rather than present-day page layouts, determine historical link selection.
